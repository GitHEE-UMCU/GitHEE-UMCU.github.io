# GitHEE-UMCU Documentation

Welcome to the central documentation hub for all GitHEE-UMCU repositories.

## About

This site is automatically updated whenever a repository's `docs/` folder is changed. Each repository in the organization contributes its own section to this site.

## Repositories

Browse documentation by repository using the navigation on the left, or use the search bar above to find what you're looking for.

## Contributing

Documentation lives in the `docs/` folder of each repository. To update a repo's docs:

1. Edit the Markdown files in `docs/`
2. Commit and push to `main`
3. This site will automatically update within a few minutes

## Need Help?

If you have questions about the documentation setup, refer to the `repo-template` repository for guidance on the structure and workflows.
